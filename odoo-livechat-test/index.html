Test Odoo Live Chat on an external website.

This independent test page is designed to verify that Odoo's native Live Chat widget works outside an Odoo-hosted website. Once you add the embed code, look for the chat bubble in the bottom-right corner.

Testing checklist

01 · Install the widgetPaste the Odoo Live Chat embed snippet in the <head> section of this HTML file.
02 · PublishUpload the file to GitHub Pages and enable Pages from the repository settings.
03 · Start a conversationOpen the public page in a private browser window and send a test message.
04 · Verify in OdooConfirm that an available operator receives the chat and can reply.
Test environment only · No customer data required
